# Visiona
VISIONA adalah Vision Smart Assistant berbasis AI yang membantu pengguna mengenali dunia di sekitar melalui kamera dan foto. Pindai uang, baca teks, deskripsikan lingkungan, kenali produk dan warna, serta dengarkan hasilnya dengan suara. Mendukung Gemini dan Grok serta tersedia sebagai PWA.
