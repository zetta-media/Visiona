Cara Penggunaan

Panduan Cepat

  1. Buka menu Pengaturan AI dan masukkan API Key Google Gemini atau Grok Anda.
  2. Kembali ke Menu Utama dan pilih fitur yang ingin Anda gunakan (misal: Pindai Uang atau Baca Teks).
  3. Arahkan kamera ke objek atau dokumen.
  4. Tekan tombol Ambil Gambar.
  5. Tekan tombol Analisis Gambar.
  6. Dengarkan hasil analisis yang dibacakan secara otomatis oleh aplikasi.

Aksesibilitas & Pembaca Layar

VISIONA dirancang sepenuhnya ramah Screen Reader (TalkBack, Jieshuo, NVDA). Gunakan navigasi usap (swipe) atau tombol Tab pada keyboard untuk berpindah antar tombol berukuran besar.

Status Sistem & PWA

Status PWA: PWA Siap / Web Browser

Kebijakan Privasi

VISIONA menghormati privasi Anda secara penuh:

  • API Key Anda disimpan secara lokal di browser (`localStorage`).
  • Tidak ada server backend milik VISIONA yang menyimpan data Anda.
  • Gambar dikirim langsung ke penyedia AI yang Anda pilih (Google Gemini atau xAI Grok).
  • Riwayat analisis disimpan sepenuhnya di perangkat Anda.

Hapus Data Lokal

Menghapus seluruh API key, riwayat, dan pengaturan yang tersimpan di perangkat ini.
